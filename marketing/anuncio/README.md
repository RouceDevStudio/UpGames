# Anuncio publicitario de UpGames

Animación vertical **1080×1920, 30 fps, sin audio** (la locución se agrega después). Fuente: `anuncio.html`. Para grabar el video, `node render.js salida.mp4` (necesita Playwright y ffmpeg).

- Vista previa en Chrome: `anuncio.html?play` (tiempo real) o `anuncio.html?t=57.4` (un instante).
- Los tiempos de cada escena están en el objeto `T` al inicio del script: si la locución final dura distinto, se ajustan ahí y se vuelve a grabar.
